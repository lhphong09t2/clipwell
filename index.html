Technical FAQ

Permissions, Table Parsing & Licensing Details

Transparent answers for security-conscious engineers, analysts, and researchers.

Why does Clipwell use activeTab instead of broad all-sites permissions? +
Extensions requesting <all_urls> can read banking, email, and internal admin tabs silently in the background. Clipwell uses Chrome's activeTab + scripting model so it cannot inspect any webpage until you explicitly click the Clipwell icon on that tab.
How does Clipwell handle complex HTML tables with colspan, rowspan, or ARIA roles? +
Clipwell constructs an in-memory 2D occupancy grid that expands merged colspan and rowspan cells, flattens internal <br> line breaks, and escapes literal | characters so tables paste cleanly into Notion, Obsidian, GitHub GFM, Excel, and Google Sheets.
How many computers can I activate with one CLIP-XXXX-XXXX-XXXX Pro key? +
Every $29 Clipwell Pro Lifetime key includes up to 5 concurrent browser profile activations across macOS, Windows, and Linux.
Does Clipwell work offline or on flights? +
Yes. Clipwell Free triggers zero network requests at all times. Clipwell Pro caches validation locally in chrome.storage.local, revalidating once every 12 hours when online with a full 7-day offline grace window.
Is Clipwell Pro a recurring subscription? +
No. Clipwell Pro is a $29 one-time purchase processed securely via Polar.sh (Stripe) with lifetime v1.x updates included.
